## Verification and visual QA

`npx tsx scripts/verify-pip-candidates.ts` reproduces the read-only shortlist. It checks actual chain ID, collection code and name; verifies NFT existence without storing holder addresses; reads tokenURI at one block; records that block's hash and timestamp; fetches metadata and original WebP from fixed IPFS gateways; saves raw metadata and unchanged artwork bytes with SHA-256 hashes and WebP dimensions. Re-running updates the dated snapshot; review before committing. SHA-256 identifies local bytes, not independent IPFS CID validation. No image generation or transformation was used.
